# 🌐 AI-Powered Language Translation Tool

## 📖 Project Overview
This is an AI/ML-based Language Translation Tool that allows users to translate text between multiple languages instantly. It utilizes Neural Machine Translation (NMT) APIs to provide accurate translations, complete with AI confidence scoring and text-to-speech capabilities.

##  Key Features
- **Multi-Language Support:** Supports 15+ languages including English, Telugu, Hindi, Tamil, Spanish, French, Korean, and more.
- **AI Translation Engine:** Uses MyMemory Neural Machine Translation API.
- **AI Confidence Metrics:** Displays the AI model used and its confidence score for the translation.
- **Text-to-Speech (TTS):** Listen to the pronunciation of both source and translated text.
- **User-Friendly UI:** Clean, responsive, and modern interface.
- **Copy to Clipboard:** One-click copy for translated text.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Python, Flask (REST API)
- **AI/ML Integration:** MyMemory NMT API, Web Speech API
